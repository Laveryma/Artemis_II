# Artemis Family Tracker

A lightweight static web app for iPhone home-screen use.

## What it does
- Shows mission elapsed time from the Artemis II launch
- Estimates the current flight day and mission phase from NASA's published daily agenda
- Shows a "Where is Orion now?" panel based on the published mission plan
- Includes gentle mission sound buttons and optional phase-change chimes
- Presents the crew as quick family-friendly cards
- Opens NASA's live Artemis tracker, live updates, and live video
- Includes simple family-friendly answers to the questions asked on launch night

## Best way to use it on iPhone
Because iPhone apps normally need Xcode and App Store or TestFlight signing, this package is built as a small web app instead.

### Fastest route
1. Open `https://laveryma.github.io/Artemis_II/` on the iPhone in Safari after GitHub Pages finishes publishing.
2. Tap **Share** > **Add to Home Screen**.
3. Use it like a small app from the home screen.

### GitHub Pages
- Repository: `laveryma/Artemis_II`
- Site URL: `https://laveryma.github.io/Artemis_II/`

### Other static hosts
1. Upload this folder to Netlify or any other static web host.
2. Open the hosted URL on the iPhone in Safari.
3. Tap **Share** > **Add to Home Screen**.

That makes it feel like a simple app on the phone.
